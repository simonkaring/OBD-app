# Meaning

12V auxiliary battery voltage dropped below 11.0 volts during active operation.

# Symptoms

- Dim lights
- Erratic sensor readings
- DC-DC converter warning

# Possible Fixes

- Test 12V auxiliary battery health
- Check DC-DC converter 12V output
- Clean battery terminal connections
