# Meaning

The Battery Management System (BMS) detected internal resistance imbalance or voltage degradation across cell modules.

# Symptoms

- Reduced EV driving range
- Check EV system warning light
- Power limited mode

# Possible Fixes

- Inspect cell module voltages
- Verify BMS wiring harness
- Perform battery module balancing or pack replacement
