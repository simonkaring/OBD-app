# Meaning

Phase current mismatch detected in high-voltage electric motor inverter circuit.

# Symptoms

- Loss of drive torque
- Immediate HV shutdown

# Possible Fixes

- Inspect inverter power transistors (IGBTs)
- Check motor phase cable connections
