# Meaning

CAN gateway lost high-speed communication with the primary Engine/Powertrain Control Module.

# Symptoms

- Instrument cluster warning messages
- Intermittent telemetry dropouts

# Possible Fixes

- Check CAN bus termination resistor (120 Ohm)
- Inspect OBD2 port wiring
- Check main relay and fuse
