# App Icon Replacement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace VoltLink's app icon with the supplied artwork and package it into `build/VoltLink.ipa`.

**Architecture:** The app catalog contains one universal 1024-by-1024 source icon. Generate that source directly from the supplied SVG, allowing Xcode's asset compiler to create platform renditions during archive. Package the archive with the existing IPA flow.

**Tech Stack:** SVG, macOS image conversion, Xcode asset catalogs, `xcodebuild`.

## Global Constraints

- Preserve the supplied SVG artwork unchanged.
- Add no dependencies or asset-catalog variants.
- Verify both the source icon dimensions and final IPA archive contents.

---

### Task 1: Replace and package the app icon

**Files:**
- Modify: `App/Assets.xcassets/AppIcon.appiconset/icon-1024.png`
- Modify: `build/VoltLink.ipa`

**Interfaces:**
- Consumes: The supplied SVG artwork.
- Produces: A 1024-by-1024 PNG source icon and a rebuildable IPA containing the compiled asset catalog.

- [ ] **Step 1: Rasterize the supplied SVG at the asset catalog's required resolution**

Run the macOS image conversion tool with a 1024-by-1024 output and write the result to `App/Assets.xcassets/AppIcon.appiconset/icon-1024.png`.

- [ ] **Step 2: Verify the source icon**

Run: `sips -g pixelWidth -g pixelHeight App/Assets.xcassets/AppIcon.appiconset/icon-1024.png`

Expected: `pixelWidth: 1024` and `pixelHeight: 1024`.

- [ ] **Step 3: Build and package the release IPA**

Run the project's release archive/package command to overwrite `build/VoltLink.ipa`.

- [ ] **Step 4: Verify the package**

Run: `unzip -l build/VoltLink.ipa | rg 'Payload/VoltLink.app/(Assets.car|Info.plist)'`

Expected: both files are present.
